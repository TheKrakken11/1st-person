Help

Click to begin control

Absolute altitude = height above sea level

AGL = height above ground

Ascent/descent rate = how fast you're falling/rising

Velocity = total speed

Mach No = speed in Mach

The sphere at the bottom right shows attitude

Top right "eng 1" and "eng 2" spaces show engine status

Mouse forward/back = nose down/up

Mouse left/right = roll left/right

Q/E = nose left/right

W/S = nose up/down

A/D = roll left/right

Up/down arrow = throttle up/down

"1" key = engine 1 on/off

"2" key = engine 2 on/off
